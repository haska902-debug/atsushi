# 写真整理アプリ（photo_organizer）

同じ人物が写っている写真だけを見つけ出し、**撮影月ごとのフォルダ**に分けて、
**写真の内容が分かるタイトル**をファイル名に付けて保存します。

```
整理後/
├── 2024-03/
│   ├── 2024-03-15_海辺で夕日を眺める.jpg
│   └── 2024-03-20_誕生日ケーキのろうそくを吹き消す.jpg
├── 2024-05/
│   └── 2024-05-02_雪の公園で雪だるま作り.jpg
└── 整理結果.csv   ← 元ファイル・タイトル・説明の一覧（Excel で開けます）
```

## しくみ

| 処理 | 使っているもの |
| --- | --- |
| 同じ人物かどうかの判定 | OpenCV の顔検出（YuNet）＋顔照合（SFace）。参照写真の顔と比べます。パソコン内で処理し、写真は外部に送りません |
| 撮影月の判定 | 写真の EXIF 撮影日時（無い場合はファイルの更新日時） |
| タイトル付け | **無料版**: パソコン内で動く AI（Ollama）／**通常版**: Claude API。どちらも画像を見て「海辺で夕日を眺める」のような日本語タイトルを作成します。人物が誰かの特定はしません |

## 準備

Python 3.10 以上が必要です。

```bash
pip install -r requirements.txt
```

初回実行時に顔認識モデル（約 40MB）を自動でダウンロードします。

タイトル付けの方法を、次のどちらかから選んで準備してください。

### 無料版（パソコン内の AI を使う）

1. https://ollama.com から Ollama をダウンロードしてインストールし、起動します。
2. 画像が分かる AI モデルを取得します（初回のみ、約 3GB）。

   ```bash
   ollama pull gemma3:4b
   ```

- 費用はかからず、写真がパソコンの外に送られることもありません。
- メモリ 8GB 以上を推奨します。1 枚あたり数秒〜十数秒かかります（パソコンの性能によります）。
- より自然なタイトルにしたい場合は、性能の高いパソコンなら `ollama pull qwen2.5vl:7b` を取得して
  `--model qwen2.5vl:7b` を付けると精度が上がります。

### 通常版（Claude API を使う・有料）

Anthropic の API キーが必要です（https://console.anthropic.com で取得）。

```bash
# macOS / Linux
export ANTHROPIC_API_KEY="sk-ant-..."
# Windows (PowerShell)
$env:ANTHROPIC_API_KEY="sk-ant-..."
```

## 使い方

1. 探したい人物の顔がはっきり写った写真を 1〜数枚、`参照` フォルダに入れます
   （正面・横顔など複数あると精度が上がります）。
2. 次のように実行します。

```bash
# 無料版
python -m photo_organizer 写真フォルダ 整理後フォルダ --ref 参照 --free

# 通常版（Claude API）
python -m photo_organizer 写真フォルダ 整理後フォルダ --ref 参照
```

まずは保存せずに結果だけ確認したいときは `--dry-run` を付けてください。

### オプション

| オプション | 内容 |
| --- | --- |
| `--ref` / `-r` | 参照写真（ファイルまたはフォルダ、複数指定可）※必須 |
| `--dry-run` | 保存せず、どう振り分けるかだけ表示 |
| `--move` | コピーではなく移動（元フォルダから無くなります） |
| `--threshold` / `-t` | 同一人物とみなす類似度（既定 0.363）。取りこぼしが多いときは 0.30 などに下げ、別人が混ざるときは 0.45 などに上げる |
| `--no-title` | AI タイトルを付けない（`2024-03-15_写真_120000.jpg` のような名前になります） |
| `--free` | 無料版（パソコン内の AI）でタイトルを作る |
| `--model` | タイトル作成に使うモデル（既定: 無料版 `gemma3:4b`／通常版 `claude-opus-5-5`） |
| `--ollama-url` | Ollama の接続先（既定 `http://localhost:11434`） |
| `--workers` | タイトル作成の同時実行数（既定: 無料版 1／通常版 4） |

## 補足

- サブフォルダ内の写真もまとめて対象になります。整理後フォルダが写真フォルダの中にあっても二重に処理しません。
- 集合写真でも、参照人物の顔が含まれていれば対象になります。
- 同じ日に同じタイトルが付いた場合は `_2`, `_3` を付けて上書きを防ぎます。
- 対応形式: JPEG / PNG / WebP / BMP / TIFF / HEIC（iPhone）
- 通常版ではリサイズした画像（長辺 1568px）だけを Claude API に送信します。無料版は外部に送信しません。
  AI がタイトルを作れなかった写真は撮影時刻の名前で保存されます。
